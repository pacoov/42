## 1. « NEXORA » : avis défavorable

Le terme est déjà largement utilisé, dans le logiciel et ailleurs, ce qui crée un risque de confusion et de conflit même si aucune marque française identique n'est apparue dans les recherches :

Conclusion : même si le dépôt en France restait juridiquement possible, le nom est banalisé, difficile à référencer, et associé à un projet crypto. **Recommandation : ne pas le conserver** pour le produit. Il reste un nom de travail interne.

## 2. Critères pour le nouveau nom

1. Prononçable en français, sans accent problématique dans une URL.
2. Évoque le suivi, la pièce, l'échéance ou la sous-traitance, sans être descriptif au point d'être indéposable (« Attestation de vigilance » ne se dépose pas).
3. Aucun résultat homonyme dans le logiciel, le BTP ou la finance en France.
4. Domaine `.fr` disponible (et idéalement `.com` ou `.app`).
5. Ne pas s'approcher des concurrents : Once For All, Attestation Légale, Aprovall, Provigis, AddWorking, Subclic, Othentis, Quitus, Bativigie (éviter « vigie », « attestation », « légale », « approval »).

## 3. Pistes (toutes [non vérifié] : une recherche web rapide n'a rien remonté, ce qui n'est pas une preuve)

| Piste | Idée | Remarque |
|---|---|---|
| **Semestra** | Le cycle de 6 mois de l'attestation URSSAF | Facile à expliquer : « tous les six mois ». Mot assez générique, à tester sur data.inpi.fr |
| **Échéo** | Échéance | Court, mémorisable ; accent à retirer dans le domaine (echeo.fr) |
| **Soutra** | Sous-traitance, en abrégé | Court, un peu abstrait |
| **Pièsa** | Les pièces du dossier | Sonorité agréable, accent dans l'URL (piesa.fr) |
| **Dossio** | Le dossier | Clair, suffixe « -io » courant dans le logiciel |
| **Veillo** | Veiller | Doux, évoque la vigilance sans le mot |
| **Attesto** | Attestation | Descriptif, donc protection faible ; à éviter si on veut une marque forte |
| **Vigilo** | Vigilance | Mot très courant à l'international, risque élevé d'homonymes hors des recherches faites |
| **Sûrtrait** | Sûr + sous-traitant | Jeu de mots, mais accent et lecture difficile |
| **Tenue** | « Tenir ses dossiers » | Mot commun, protection difficile ; charmant en usage |

Écartés après recherche : **Cadrio** (logiciel français de trésorerie existant [tiers]), tout ce qui contient « vigie » (Bativigie).

Recommandation de court terme : garder trois finalistes (par exemple Semestra, Échéo, Dossio), faire les vérifications de la section 4, puis tester le nom retenu auprès de deux ou trois artisans à la fin des entretiens (« ça vous évoque quoi ? »).

## 4. Vérifications à faire par le fondateur (gratuites)

1. **data.inpi.fr → Marques** : recherche à l'identique du nom, filtre « marques en vigueur », classes 9 (logiciels) et 42 (services informatiques, SaaS). Regarder aussi les orthographes proches à la main.
2. **EUIPO (euipo.europa.eu, eSearch plus)** : même recherche au niveau européen.
3. **annuaire-entreprises.data.gouv.fr** : dénominations sociales identiques ou proches.
4. **Noms de domaine** : disponibilité de `nom.fr` (registre AFNIC, via n'importe quel bureau d'enregistrement) et `nom.com`.
5. **Réseaux et moteurs** : taper le nom avec « logiciel », « BTP », « avis » pour voir ce qui remonte.
6. Si un finaliste passe ces filtres : envisager une recherche de similarité payante à l'INPI avant dépôt (tarif à vérifier sur inpi.fr) ; un dépôt de marque française en 1 classe coûte quelques centaines d'euros (à confirmer sur inpi.fr) et n'est pas une urgence tant que le produit n'est pas commercialisé.
